САМЫЙ ПРОСТОЙ СПОСОБ (рекомендуется):

    ./start.sh

Этот скрипт автоматически:
  1. Проверит Python 3
  2. Создаст виртуальное окружение
  3. Установит зависимости (PyTorch, Transformers, ChromaDB и др.)
  4. Настроит структуру проекта
  5. Запустит приложение


АЛЬТЕРНАТИВНЫЕ СПОСОБЫ:

Вариант 1 - Раздельно:
    ./setup.sh    # Один раз для настройки
    ./run.sh      # Для запуска

Вариант 2 - Make:
    make setup
    make run

Вариант 3 - Docker:
    ./docker-run.sh

Вариант 4 - Вручную:
    source venv/bin/activate
    python3 src/main.py
