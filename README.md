# NeuroGenesis 🧠
Проект: «растущий разум» с активной семантической памятью

## Описание

NeuroGenesis — это проект по созданию системы искусственного интеллекта с активной семантической памятью, способной к обучению и "росту".

## Быстрый старт

### 🚀 Самый простой способ (рекомендуется)

**Один скрипт делает всё — настройку и запуск:**

```bash
./start.sh
```

Этот скрипт автоматически:
- Проверит системные требования
- Создаст виртуальное окружение
- Установит все зависимости
- Настроит структуру проекта
- Запустит NeuroGenesis

### Альтернативные варианты

#### Вариант 1: Раздельная настройка и запуск

1. **Настройка окружения:**
   ```bash
   ./setup.sh
   ```

2. **Запуск проекта:**
   ```bash
   ./run.sh
   ```

#### Вариант 2: Использование Makefile

```bash
make setup    # Настройка
make run      # Запуск
make help     # Показать все команды
```

#### Вариант 3: Запуск в Docker

1. **Запуск через Docker:**
   ```bash
   ./docker-run.sh
   ```

2. **Просмотр логов:**
   ```bash
   docker-compose logs -f
   ```

3. **Остановка:**
   ```bash
   docker-compose down
   ```

## Структура проекта

```
NeuroGenesis/
├── start.sh              # 🚀 ГЛАВНЫЙ СКРИПТ - запускает всё
├── setup.sh              # Скрипт настройки окружения
├── run.sh                # Скрипт запуска проекта
├── docker-run.sh         # Скрипт запуска через Docker
├── Makefile              # Команды для удобного управления
├── requirements.txt      # Зависимости Python
├── Dockerfile            # Конфигурация Docker
├── docker-compose.yml    # Docker Compose конфигурация
├── src/                  # Исходный код
│   ├── main.py          # Точка входа
│   ├── core/            # Ядро системы
│   ├── memory/          # Семантическая память
│   └── utils/           # Утилиты
├── data/                 # Данные
├── models/              # Модели
├── logs/                # Логи
├── config/              # Конфигурации
└── tests/               # Тесты
```

## Требования

- Python 3.8+
- pip
- (опционально) Docker и docker-compose

## Разработка

### Активация виртуального окружения

```bash
source venv/bin/activate
```

### Запуск тестов

```bash
pytest tests/
```

### Установка дополнительных зависимостей

```bash
pip install <package-name>
pip freeze > requirements.txt
```

## Конфигурация

Настройки проекта находятся в файле `.env`. Основные параметры:

- `DEBUG` - режим отладки
- `LOG_LEVEL` - уровень логирования
- `DATA_DIR` - директория для данных
- `MODELS_DIR` - директория для моделей
- `LOGS_DIR` - директория для логов
